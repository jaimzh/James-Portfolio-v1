The mental model

        

          
1. Choose a rootThe bordered scroll box is the observer’s world.

          
2. Adjust its boundaryNegative root margins shrink that world to the yellow zone.

          
3. Watch targetsThe callback runs when a watched target crosses the chosen threshold.

  display: grid;
  grid-template-rows: 0fr;
  overflow: hidden;
  transition: grid-template-rows 0.4s ease;
}

.image-inner {
  min-height: 0;
  overflow: hidden;
}

.card:hover .image-wrapper {
  grid-template-rows: 1fr;
